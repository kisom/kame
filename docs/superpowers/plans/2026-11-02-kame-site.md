# kame-site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A command line tool, `kame-site`, with `new` and `build`, that turns `.kame` documents and Markdown pages into a static site with an RSS feed.

**Architecture:** A new `crates/kame-site` crate, a library plus a thin binary, on top of `kame-core`. Building is split into working out the site, which is a pure map from output path to content (`Plan`), and writing it atomically, so that nearly everything can be tested without touching `output/`.

**Tech Stack:** Rust 2021, `kame-core`, `yaml_serde` 0.10, `minijinja` 3, `pulldown-cmark` 0.13 with `html`.

**Spec:** `docs/superpowers/specs/2026-11-02-kame-site-design.md`

## Global Constraints

- `kame-core` must keep no GUI or text engine dependency, and `kame-site` must not depend on `kame-typeset`.
- New dependencies apply only to `kame-site`: `yaml_serde` 0.10, `minijinja` 3, `pulldown-cmark` 0.13 with `html`.
- Linux and macOS only.
- Source documents are only ever read, with `Db::open_read_only`.
- The same input gives byte-identical output: no build timestamps, everything sorted.
- All text offsets are byte offsets.
- `cargo` is on PATH on talos. On straylight, prefix with `nix-shell -p cargo rustc gcc pkg-config --run '...'`.
- Both `cargo build` and `cargo test` at the root must pass after every task. Run `cargo fmt --all` before each commit.
- No shell message bodies in double quotes containing backticks. Pass commit messages by heredoc with a quoted delimiter.
- End every commit message with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01QVmUX6xuvMN6FY7nCiSbpz
  ```
- Work on a branch from `master`. Rebase and fast-forward only, never merge.

## Review Focus

1. **A document open in kame while building.** Someone will build with the essay still open, so the read must succeed and see the saved text, not fail on a lock. Pinned in Task 4.
2. **A tag that reduces to nothing, or isn't ASCII.** `"!!!"` must be an error naming the document rather than a page at `/tags//`, and `"Économie"` must keep its letters. Pinned in Task 4.
3. **Image file names with spaces, quotes or Unicode, and two images sharing a name.** The page must link them correctly, and a path can't escape the page's directory. Pinned in Task 5.
4. **`site.url` written with a trailing slash.** `https://example.com/` must not produce `https://example.com//k/a/` in the feed. Pinned in Task 2.
5. **Text in a feed that could break XML.** `]]>`, `&`, and control characters from pasted text must still give a well-formed feed. Pinned in Task 8.

```rust
    /// Reads `YYYY-MM-DD`, optionally followed by `HH:MM` or `HH:MM:SS` as Markdown from
    /// Pelican carries. The time has to make sense, and is then ignored.
    pub fn parse(text: &str) -> Option<Date> {
        let text = text.trim();
        let (day, time) = match text.split_once(' ') {
            Some((day, time)) => (day, Some(time)),
            None => (text, None),
        };
        if let Some(time) = time {
            let parts: Vec<&str> = time.split(':').collect();
            if !matches!(parts.len(), 2 | 3) {
                return None;
            }
            let limits = [24, 60, 60];
            for (part, limit) in parts.iter().zip(limits) {
                if part.len() != 2 || part.parse::<u8>().ok()? >= limit {
                    return None;
                }
            }
        }
        let parts: Vec<&str> = day.split('-').collect();
        let [year, month, day] = parts.as_slice() else {
            return None;
        };
        if year.len() != 4 || month.len() != 2 || day.len() != 2 {
            return None;
        }
        let year: i32 = year.parse().ok()?;
        let month: u8 = month.parse().ok()?;
        let day: u8 = day.parse().ok()?;
        let leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
        let days = match month {
            1 | 3 | 5 | 7 | 8 | 10 | 12 => 31,
            4 | 6 | 9 | 11 => 30,
            2 if leap => 29,
            2 => 28,
            _ => return None,
        };
        (1..=days).contains(&day).then_some(Date { year, month, day })
    }

    /// The day `when` falls on, in UTC.
    pub fn from_system_time(when: SystemTime) -> Date {
        Date::parse(&crate::session::iso_date(when)).expect("iso_date writes a valid date")
    }

    /// The form RSS requires, at midnight UTC, since kame's dates are days.
    pub fn rfc822(&self) -> String {
        const WEEKDAYS: [&str; 7] = ["Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"];
        const MONTHS: [&str; 12] = [
            "Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec",
        ];
        // Sakamoto's method.
        const OFFSETS: [i32; 12] = [0, 3, 2, 5, 0, 3, 5, 1, 4, 6, 2, 4];
        let month = usize::from(self.month) - 1;
        let year = if self.month < 3 { self.year - 1 } else { self.year };
        let weekday =
            (year + year / 4 - year / 100 + year / 400 + OFFSETS[month] + i32::from(self.day)) % 7;
        format!(
            "{}, {:02} {} {:04} 00:00:00 GMT",
            WEEKDAYS[weekday as usize], self.day, MONTHS[month], self.year
        )
    }
```

```rust
use std::borrow::Cow;

use crate::model::{AnnotationKind, BlockKind, Document};

/// `doc` without a first heading repeating `title`, for a page that prints the title itself.
/// It stays if a footnote is anchored in it, since the footnote would lose its place.
pub fn without_repeated_title<'a>(doc: &'a Document, title: &str) -> Cow<'a, Document> {
    let repeats = doc.blocks.first().is_some_and(|first| {
        matches!(first.kind, BlockKind::Heading { .. })
            && first.text == title
            && !doc.annotations.iter().any(|annotation| {
                annotation.kind == AnnotationKind::Footnote
                    && annotation.anchor.block_id() == first.id
            })
    });
    if !repeats {
        return Cow::Borrowed(doc);
    }
    let mut rest = doc.clone();
    rest.blocks.remove(0);
    Cow::Owned(rest)
}
```

```rust
/// A map that refuses a repeated key. A plain map keeps the last of a duplicate, which
/// would quietly drop a document.
#[derive(Debug, Default)]
struct UniqueMap(BTreeMap<String, String>);

impl<'de> Deserialize<'de> for UniqueMap {
    fn deserialize<D: Deserializer<'de>>(deserializer: D) -> Result<Self, D::Error> {
        struct UniqueVisitor;

        impl<'de> Visitor<'de> for UniqueVisitor {
            type Value = UniqueMap;

            fn expecting(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
                f.write_str("a map of slugs to files")
            }

            fn visit_map<A: MapAccess<'de>>(self, mut map: A) -> Result<UniqueMap, A::Error> {
                let mut found = BTreeMap::new();
                while let Some((slug, path)) = map.next_entry::<String, String>()? {
                    if found.insert(slug.clone(), path).is_some() {
                        return Err(serde::de::Error::custom(format!(
                            "the slug \"{slug}\" appears twice"
                        )));
                    }
                }
                Ok(UniqueMap(found))
            }
        }

        deserializer.deserialize_map(UniqueVisitor)
    }
}
```

```rust
                .into_iter()
                .map(|(slug, path)| Entry {
                    slug,
                    path: resolve_open_path(&path, &base),
                })
                .collect()
        };
        let publish = entries(site.publish);
        let drafts = entries(site.drafts);

        let mut errors = Vec::new();
        let mut slugs = BTreeMap::new();
        let mut files = BTreeMap::new();
        for entry in publish.iter().chain(&drafts) {
```

```rust
/// A tag as it appears in a URL: lowercase, with anything but letters and digits as a single
/// hyphen. Letters from any alphabet stay. Can be empty, which callers treat as an error.
pub fn tag_slug(name: &str) -> String {
    let mut slug = String::new();
    for c in name.chars().flat_map(char::to_lowercase) {
        if c.is_alphanumeric() {
            slug.push(c);
        } else if !slug.is_empty() && !slug.ends_with('-') {
            slug.push('-');
        }
    }
    slug.trim_end_matches('-').to_string()
}

/// The day a document's file last changed, for one with no date of its own.
fn file_date(path: &std::path::Path) -> Option<Date> {
    use std::os::unix::fs::MetadataExt;
    let seconds = std::fs::metadata(path).ok()?.ctime();
    let when = std::time::UNIX_EPOCH + std::time::Duration::from_secs(u64::try_from(seconds).ok()?);
    Some(Date::from_system_time(when))
}

/// Reads one document, reporting what is wrong with it. Nothing is ever written.
pub fn read(entry: &Entry, draft: bool, problems: &mut Problems) -> Option<Source> {
    let path = &entry.path;
    let slug = &entry.slug;
    if !path.is_file() {
        problems
            .errors
            .push(format!("\"{slug}\": no document at {}", path.display()));
        return None;
    }
    let loaded = kame_core::storage::Db::open_read_only(path)
        .and_then(|db| Ok((db.load_document()?, db.load_metadata().ok().flatten())));
    let (doc, metadata) = match loaded {
        Ok(loaded) => loaded,
        Err(err) => {
            problems.errors.push(format!(
                "\"{slug}\": could not read {}: {err}. If it was last saved by an older kame, open it in kame once.",
                path.display()
            ));
            return None;
        }
    };
    let metadata = metadata.unwrap_or_default();

    let stem = || {
        path.file_stem()
            .map(|stem| stem.to_string_lossy().into_owned())
            .unwrap_or_else(|| slug.clone())
    };
    let title = [&metadata.title, &doc.title]
        .into_iter()
        .find(|title| !title.is_empty() && title.as_str() != "Untitled")
        .cloned()
        .unwrap_or_else(stem);

    let written = [&metadata.published, &metadata.created]
        .into_iter()
        .find(|date| !date.trim().is_empty());
    let date = match written {
        Some(text) => match Date::parse(text) {
            Some(date) => date,
            None => {
                problems
                    .errors
                    .push(format!("\"{slug}\": \"{text}\" isn't a date: use YYYY-MM-DD"));
                return None;
            }
        },
        None => {
            problems.warnings.push(format!(
                "\"{slug}\" has no date of its own, so it is using its file's"
            ));
            match file_date(path) {
                Some(date) => date,
                None => {
                    problems
                        .errors
                        .push(format!("\"{slug}\": could not read a date for {}", path.display()));
                    return None;
                }
            }
        }
    };

    let mut tags = Vec::new();
    for name in &metadata.tags {
        let tag_url = tag_slug(name);
        if tag_url.is_empty() {
            problems
                .errors
                .push(format!("\"{slug}\": the tag \"{name}\" has no letters or digits"));
            return None;
        }
        tags.push(Tag {
            name: name.clone(),
            slug: tag_url,
        });
    }

    let doc = kame_core::export::without_repeated_title(&doc, &title).into_owned();
    Some(Source {
        slug: slug.clone(),
        path: path.clone(),
        draft,
        title,
        author: metadata.author,
        date,
        tags,
        doc,
    })
}

/// Reads a site's documents: published ones newest first, then by slug, then drafts in the
/// same order.
pub fn read_all(config: &Config, include_drafts: bool, problems: &mut Problems) -> Vec<Source> {
    let order = |a: &Source, b: &Source| b.date.cmp(&a.date).then_with(|| a.slug.cmp(&b.slug));
    let mut published: Vec<Source> = config
```

```rust
impl SiteIndex {
    pub fn new(sources: &[Source]) -> SiteIndex {
        let by_file = sources
            .iter()
            .filter_map(|source| {
                let file = source.path.canonicalize().ok()?;
                Some((file, (source.url(), source.draft)))
            })
            .collect();
        SiteIndex { by_file }
    }

    /// The site URL a document link leads to, or `None` to publish it as text. A published
    /// document never links to a draft, so publishing can't reveal one. A `#Heading` is
    /// ignored, so one with no file leads nowhere.
    pub fn link_url(&self, target: &str, from: &Source) -> Option<String> {
        let (path, _heading) = split_document_target(target);
        if path.is_empty() {
            return None;
        }
        let file = find_document(path, &from.path)?.canonicalize().ok()?;
        let (url, draft) = self.by_file.get(&file)?;
        (!*draft || from.draft).then(|| url.clone())
    }
}

/// `text` as it can appear in a URL's path.
fn percent_encode(text: &str) -> String {
    let mut out = String::new();
    for byte in text.bytes() {
        match byte {
            b'A'..=b'Z' | b'a'..=b'z' | b'0'..=b'9' | b'-' | b'.' | b'_' | b'~' => {
                out.push(byte as char)
            }
            _ => out.push_str(&format!("%{byte:02X}")),
        }
    }
    out
}

impl Images {
    /// Works out where each image block's file goes, in reading order, so that two files
    /// sharing a name are told apart the same way on every build.
    pub fn resolve(source: &Source, site_dir: &Path, problems: &mut Problems) -> Images {
        let base = source.path.parent().unwrap_or(Path::new(""));
        let mut copies: Vec<(String, PathBuf)> = Vec::new();
        let mut named = HashMap::new();
        for block in &source.doc.blocks {
            let BlockKind::Image { path, .. } = &block.kind else {
                continue;
            };
            if named.contains_key(path) || path.starts_with("http://") || path.starts_with("https://") {
                continue;
            }
            if path.starts_with('/')
                && !Path::new(path).is_file()
                && site_dir.join("static").join(path.trim_start_matches('/')).is_file()
            {
                continue;
            }
            let file = base.join(path);
            let Ok(file) = file.canonicalize() else {
                problems
                    .warnings
                    .push(format!("\"{}\": no image at {path}", source.slug));
                continue;
            };
            if !file.is_file() {
                problems
                    .warnings
                    .push(format!("\"{}\": no image at {path}", source.slug));
                continue;
            }
            if let Some((name, _)) = copies.iter().find(|(_, existing)| *existing == file) {
                named.insert(path.clone(), name.clone());
                continue;
            }
            let name = unique_name(&file, &copies);
            named.insert(path.clone(), name.clone());
            copies.push((name, file));
        }
        Images { copies, named }
    }

    /// Each file to copy beside the page, as its name there and where it comes from.
    pub fn copies(&self) -> &[(String, PathBuf)] {
        &self.copies
    }

    /// The image's URL from the page beside it.
    pub fn relative(&self, path: &str) -> String {
        match self.named.get(path) {
            Some(name) => percent_encode(name),
            None => path.to_string(),
        }
    }

    /// The image's URL from anywhere, as a feed needs.
    pub fn absolute(&self, path: &str, site_url: &str, doc_url: &str) -> String {
        match self.named.get(path) {
            Some(name) => format!("{site_url}{doc_url}{}", percent_encode(name)),
            None if path.starts_with('/') => format!("{site_url}{path}"),
            None => path.to_string(),
        }
    }
}

/// `file`'s name, or with `-2`, `-3` and so on if another file has taken it.
fn unique_name(file: &Path, copies: &[(String, PathBuf)]) -> String {
    let name = file
        .file_name()
        .map(|name| name.to_string_lossy().into_owned())
        .unwrap_or_else(|| "image".to_string());
    let taken = |candidate: &str| copies.iter().any(|(existing, _)| existing == candidate);
    if !taken(&name) {
        return name;
    }
    let stem = file
        .file_stem()
        .map(|stem| stem.to_string_lossy().into_owned())
        .unwrap_or_default();
    let extension = file
        .extension()
        .map(|extension| format!(".{}", extension.to_string_lossy()))
        .unwrap_or_default();
    (2..)
        .map(|number| format!("{stem}-{number}{extension}"))
        .find(|candidate| !taken(candidate))
        .expect("there is always another number")
}

/// Records each document link that will publish as text, so that rot is visible.
pub fn note_unpublished_links(source: &Source, index: &SiteIndex, problems: &mut Problems) {
    for block in &source.doc.blocks {
        for span in &block.spans {
            if let SpanStyle::DocumentLink { target } = &span.style {
                if index.link_url(target, source).is_none() {
                    problems.warnings.push(format!(
                        "\"{}\": the link to {target} publishes as its text",
                        source.slug
                    ));
                }
            }
        }
    }
}
```

```rust
pub fn read_all(site_dir: &Path, problems: &mut Problems) -> Vec<Page> {
    let root = site_dir.join("pages");
    let mut files = Vec::new();
    markdown_files(&root, &mut files);
    let mut pages = Vec::new();
    for file in files {
        let relative = file.strip_prefix(&root).unwrap_or(&file);
        let source = match std::fs::read_to_string(&file) {
            Ok(source) => source,
            Err(err) => {
                problems
                    .errors
                    .push(format!("could not read {}: {err}", relative.display()));
                continue;
            }

        let body = front.as_ref().map_or(source, |found| found.body);
        let stem = file
            .file_stem()
            .map(|stem| stem.to_string_lossy().into_owned())
            .unwrap_or_default();
        let title = front
            .as_ref()
            .map(|found| found.metadata.title.clone())
            .filter(|title| !title.is_empty())
            .or_else(|| first_heading(body))
            .unwrap_or(stem);
        let template = front
            .as_ref()
            .and_then(|found| found.template.clone())
            .unwrap_or_else(|| "page.html".to_string());
        let mut html = String::new();
        pulldown_cmark::html::push_html(&mut html, Parser::new_ext(body, options()));
        let url = format!(
            "/{}/",
            relative.with_extension("").to_string_lossy().replace('\\', "/")
        );
        pages.push(Page { url, title, template, body: html });
    }
    pages.sort_by(|a, b| a.url.cmp(&b.url));
    pages
}
```

```rust
/// Writes a new site into `dir`, which can be missing or empty. Anything already there means
/// it stops, so that it can't overwrite a site.
pub fn new_site(dir: &Path) -> Result<(), String> {
    if let Ok(mut entries) = std::fs::read_dir(dir) {
        if entries.next().is_some() {
            return Err(format!("{} already has files in it", dir.display()));
        }
    }
    let write = || -> std::io::Result<()> {
        for directory in EMPTY_DIRECTORIES {
            std::fs::create_dir_all(dir.join(directory))?;
        }
        for (path, contents) in FILES {
            let target = dir.join(path);
            if let Some(parent) = target.parent() {
                std::fs::create_dir_all(parent)?;
            }
            std::fs::write(target, contents)?;
        }
        Ok(())
    };
    write().map_err(|err| format!("could not write {}: {err}", dir.display()))
}
```

```rust
use kame_core::export::{html_body, Publish};

/// `text` as XML character data. Characters XML 1.0 can't hold at all are dropped, since no
/// escaping would make them valid, and pasted text can carry them.
fn escape(text: &str) -> String {
    let mut out = String::with_capacity(text.len());
    for c in text.chars() {
        match c {
            '&' => out.push_str("&amp;"),
            '<' => out.push_str("&lt;"),
            '>' => out.push_str("&gt;"),
            '"' => out.push_str("&quot;"),
            '\t' | '\n' | '\r' => out.push(c),
            c if u32::from(c) < 0x20 || matches!(c, '\u{fffe}' | '\u{ffff}') => {}
            c => out.push(c),
        }
    }
    out
}
```

```rust
use minijinja::{context, Environment, Value};

use crate::config::Config;
use crate::pages::{self, Page};
use crate::refs::{note_unpublished_links, Images, SiteIndex};

/// Every template the theme has to have.
const TEMPLATES: [&str; 7] = [
    "base.html",
    "index.html",
    "archive.html",
    "tags.html",
    "tag.html",
    "document.html",
    "page.html",

/// A value templates print as it is: markup we rendered, or a URL, which would otherwise have
/// its slashes escaped.
fn safe(text: impl Into<String>) -> Value {
    Value::from_safe_string(text.into())
}

fn tag_url(slug: &str) -> String {
    format!("/tags/{slug}/")
}

fn document_value(source: &Source) -> Value {
    let tags: Vec<Value> = source
        .tags
        .iter()
        .map(|tag| context! { name => tag.name.clone(), url => safe(tag_url(&tag.slug)) })
        .collect();
    context! {
        title => source.title.clone(),
        date => source.date.to_string(),
        url => safe(source.url()),
        tags => tags,
    }
}

/// The path of the page at `url`: `/a/b/` is `a/b/index.html`.
fn page_path(url: &str) -> PathBuf {
    Path::new(url.trim_start_matches('/')).join("index.html")
}

/// Loads the theme's templates, naming each one that is missing or doesn't parse.
fn load_templates(site_dir: &Path, extra: &[String], problems: &mut Problems) -> Environment<'static> {
    let mut env = Environment::new();
    let root = site_dir.join("theme/templates");
    let names = TEMPLATES.iter().map(|name| name.to_string()).chain(extra.iter().cloned());
    for name in names {
        if env.get_template(&name).is_ok() {
            continue;
        }
        match std::fs::read_to_string(root.join(&name)) {
            Ok(text) => {
                if let Err(err) = env.add_template_owned(name.clone(), text) {
                    problems.errors.push(format!("theme/templates/{name}: {err}"));
                }
            }
            Err(err) => problems.errors.push(format!("theme/templates/{name}: {err}")),
        }
    }
    env
}

fn files_under(dir: &Path, found: &mut Vec<PathBuf>) {
    let Ok(entries) = std::fs::read_dir(dir) else {
        return;
    };
    let mut paths: Vec<PathBuf> = entries.flatten().map(|entry| entry.path()).collect();
    paths.sort();
    for path in paths {
        if path.is_dir() {
            files_under(&path, found);
        } else {
            found.push(path);
        }
    }
}

impl Plan {
    /// Adds a generated file, or reports what it collides with.
    fn add(&mut self, path: PathBuf, output: Output, problems: &mut Problems) {
        if self.files.contains_key(&path) {
            problems
                .errors
                .push(format!("two things want to be at {}", path.display()));
            return;
        }
        self.files.insert(path, output);
    }
}

/// Renders `template`, reporting a failure rather than stopping, so that all are reported.
fn render(env: &Environment, template: &str, values: Value, problems: &mut Problems) -> Vec<u8> {
    let rendered = env
        .get_template(template)
        .and_then(|found| found.render(values));
    match rendered {
        Ok(text) => text.into_bytes(),
        Err(err) => {
            problems.errors.push(format!("theme/templates/{template}: {err}"));
            Vec::new()
        }
    }
}

/// One tag on the site, with its published documents.
struct TagEntry<'a> {
    name: String,
    documents: Vec<&'a Source>,
}

/// Groups published documents by tag slug. Spellings differing only by case share a tag, but
/// two different tags reducing to one URL are an error.
fn group_tags<'a>(published: &[&'a Source], problems: &mut Problems) -> BTreeMap<String, TagEntry<'a>> {
    let mut tags: BTreeMap<String, TagEntry<'a>> = BTreeMap::new();
    for source in published {
        for tag in &source.tags {
            let entry = tags.entry(tag.slug.clone()).or_insert_with(|| TagEntry {
                name: tag.name.clone(),
                documents: Vec::new(),
            });
            if entry.name.to_lowercase() != tag.name.to_lowercase() {
                problems.errors.push(format!(
                    "the tags \"{}\" and \"{}\" would share /tags/{}/",
                    entry.name, tag.name, tag.slug
                ));
            }
            if !entry.documents.iter().any(|other| other.slug == source.slug) {
                entry.documents.push(source);
            }
        }
    }
    tags
}

        Ok(config) => config,
        Err(errors) => {
            problems.errors.extend(errors);
            return None;
        }
    };
    let sources = read_all(&config, include_drafts, problems);
    let pages: Vec<Page> = pages::read_all(site_dir, problems);
    let extra: Vec<String> = pages.iter().map(|page| page.template.clone()).collect();
    let env = load_templates(site_dir, &extra, problems);
    if !problems.errors.is_empty() {
        return None;
    }

    let site = context! {
        name => config.name.clone(),
        url => safe(config.url.clone()),
        description => config.description.clone(),
        author => config.author.clone(),
    };
    let kame_css = safe(STYLE);
    let index = SiteIndex::new(&sources);
    let published: Vec<&Source> = sources.iter().filter(|source| !source.draft).collect();
    let listed: Vec<Value> = published.iter().map(|source| document_value(source)).collect();

    let mut plan = Plan::default();

    // Documents, with their images beside them.
    for source in &sources {
        note_unpublished_links(source, &index, problems);
        let images = Images::resolve(source, site_dir, problems);
        let document_link = |target: &str| index.link_url(target, source);
        let image = |path: &str| images.relative(path);
        let body = html_body(
            &source.doc,
            &Publish {
                document_link: &document_link,
                image: &image,
            },
        );
        let url = source.url();
        let tags: Vec<Value> = source
            .tags
            .iter()
            .map(|tag| context! { name => tag.name.clone(), url => safe(tag_url(&tag.slug)) })
            .collect();
        let values = context! {
            site => site.clone(),
            kame_css => kame_css.clone(),
            title => source.title.clone(),
            date => source.date.to_string(),
            author => source.author.clone(),
            tags => tags,
            body => safe(body),
            url => safe(url.clone()),
            draft => source.draft,
        };
        let page = render(&env, "document.html", values, problems);
        plan.add(page_path(&url), Output::Bytes(page), problems);
        for (name, file) in images.copies() {
            let path = Path::new(url.trim_start_matches('/')).join(name);
            plan.add(path, Output::Copy(file.clone()), problems);
        }
    }

    for page in &pages {
        let values = context! {
            site => site.clone(),
            kame_css => kame_css.clone(),
            title => page.title.clone(),
            body => safe(page.body.clone()),
            url => safe(page.url.clone()),
        };
        let rendered = render(&env, &page.template, values, problems);
        plan.add(page_path(&page.url), Output::Bytes(rendered), problems);
    }

        &env,
        "index.html",
        context! { site => site.clone(), kame_css => kame_css.clone(), documents => listed.clone() },

                name => entry.name.clone(),
                url => safe(tag_url(slug)),
                count => entry.documents.len(),
            }

            &env,
            "tag.html",
            context! {
                site => site.clone(),
                kame_css => kame_css.clone(),
                tag => context! { name => entry.name.clone(), url => safe(tag_url(slug)) },
                documents => documents,
            },
            problems,
        );
        plan.add(page_path(&tag_url(slug)), Output::Bytes(page), problems);
    }

    // Static files. The site's override the theme's on purpose, and either colliding with

    let mut statics: BTreeMap<PathBuf, PathBuf> = BTreeMap::new();
    for root in [site_dir.join("theme/static"), site_dir.join("static")] {

                statics.insert(relative.to_path_buf(), file.clone());
            }
        }
    }
    for (path, file) in statics {
        plan.add(path, Output::Copy(file), problems);
    }

    problems.errors.is_empty().then_some(plan)
```

```rust
use crate::plan::Output;

/// Where a build is assembled, beside `output/` so that the final rename stays on one disk.
const BUILDING: &str = ".output-building";

pub fn write_site(plan: &Plan, site_dir: &Path) -> std::io::Result<()> {
    let building = site_dir.join(BUILDING);
    if building.exists() {
        std::fs::remove_dir_all(&building)?;
    }
    std::fs::create_dir_all(&building)?;
    for (path, output) in &plan.files {
        let target = building.join(path);
        if let Some(parent) = target.parent() {
            std::fs::create_dir_all(parent)?;
        }
        match output {
            Output::Bytes(bytes) => std::fs::write(&target, bytes)?,
            Output::Copy(source) => {
                std::fs::copy(source, &target)?;
            }
        }
    }
    let output = site_dir.join("output");
    if output.exists() {
        std::fs::remove_dir_all(&output)?;
    }
    std::fs::rename(&building, &output)
}
```

```rust
/// Builds the site at `site_dir`, replacing `output/` only if all of it succeeds.
pub fn build(site_dir: &std::path::Path, include_drafts: bool) -> Problems {
    let mut problems = Problems::default();
    if let Some(plan) = plan::build_plan(site_dir, include_drafts, &mut problems) {
        if let Err(err) = write::write_site(&plan, site_dir) {
            problems.errors.push(format!("could not write the site: {err}"));
        }
    }
    problems
}

const USAGE: &str = "usage:\n  kame-site new DIR\n  kame-site build [--no-drafts] [DIR]";

/// The command line, without its program name. Returns the exit code: 1 when the work
/// failed, and 2 when the command wasn't understood.
pub fn run(args: &[String]) -> i32 {
    let mut args = args.iter().map(String::as_str);
    match args.next() {
        Some("new") => {
            let (Some(dir), None) = (args.next(), args.next()) else {
                eprintln!("{USAGE}");
                return 2;
            };
            match starter::new_site(std::path::Path::new(dir)) {
                Ok(()) => {
                    println!("Created a site in {dir}. Edit site.yaml, then run kame-site build.");
                    0
                }
                Err(err) => {
                    eprintln!("kame-site: {err}");
                    1
                }
            }
        }
        Some("build") => {
            let mut include_drafts = true;
            let mut dir = None;
            for arg in args {
                match arg {
                    "--no-drafts" => include_drafts = false,
                    other if other.starts_with('-') || dir.is_some() => {
                        eprintln!("{USAGE}");
                        return 2;
                    }
                    other => dir = Some(other),
                }
            }
            let problems = build(std::path::Path::new(dir.unwrap_or(".")), include_drafts);
            for warning in &problems.warnings {
                eprintln!("warning: {warning}");
            }
            for error in &problems.errors {
                eprintln!("error: {error}");
            }
            i32::from(!problems.errors.is_empty())
        }
        _ => {
            eprintln!("{USAGE}");
            2
        }
    }
}
```
